# 臺灣的孩子為什麼變少？

網站：https://hardy1yang.github.io/taiwan-fertility-atlas/

臺灣全國 1947–2025、縣市 2007–2025、鄉鎮市區 2007–2025 的出生、生育率、年齡與胎次、出生數分解、可能相關的因素、托育資源，以及國發會人口推估的情境。這個 repository 只放建置好的靜態網站與一份公開資料包。

- 資料版本（run）：`b9b664b15c73`，產製 2026-10-13T06:05:12Z，部署 2026-10-13T06:38:49+00:00
- 2025 年出生數（按發生）105,676 人，官方總生育率 0.695
- 2025 年縣市總生育率最低：基隆市 0.47；最高：雲林縣 1.13
- 2015→2025 出生數減少 107,417 人：育齡女性人數 -21,101、年齡結構 -8,220、年齡別生育率 -78,096（三項相加等於實際變化）
- 全國 0–2 歲托育使用率（托嬰中心＋登記居家托育收托 ÷ 0–2 歲人口）2016 年 9.3%、2024 年 24.9%（收托 102,146 人）
- 國發會中推估（情境，不是預測）：2025→2050 重建出生數減少 48,796 人，其中育齡女性人數 -49,623、年齡結構 5,169、推估生育率 -4,341

## 品質檢查

自算的縣市年齡別生育率與官方值最大差 0.571‰、總生育率最大差 13.02‰；鄉鎮市區總生育率最大差 11.38‰。各層級加總一致，出生數分解恆等式誤差小於 1e-6。托育來源各縣市相加等於全國總計；人口推估起點的育齡女性人數與戶政司相同，以推估表重建的出生數與國發會公布值相差最多 2.97%（2025 年起點）。

## 閱讀指南

- **出生人數、粗出生率、總生育率**：三者回答不同問題。出生人數是總量；粗出生率除以全部人口，會受高齡化影響；總生育率是「假設一位女性一生都照當年各年齡的生育率生育」的合成指標，不是現在的女性已經生了幾個孩子。
- **第二胎出生占比**：是當年出生嬰兒的胎次結構，不是「生過第一胎的人再生第二胎的機率」。第一胎變少時，第二胎占比也可能上升。
- **初婚年齡與生第一胎年齡**：兩者是不同的人群（當年初婚的人、當年生第一胎的母親），只並列比較，不能相減當成個人婚後等多久才生。
- **鄉鎮市區的比率**：人數少的地區，一年多或少幾個嬰兒就會讓比率大幅跳動。預設看三年合併的值，並同時看原始出生數。
- **按發生與按登記**：本站年度數字按出生發生日期統計；新聞常引用的月報多按登記日期，兩者不可直接混比，當年最後幾個月的數字也可能尚未完整。
- **出生數分解**：把出生數的變化拆成育齡女性人數、年齡結構、年齡別生育率三部分，三者相加等於實際變化。這是會計拆解，不是原因分析。
- **跨縣市與縣市內**：跨縣市相關比較的是同一年不同的地方；縣市內（雙向固定效果）比較的是同一縣市在不同年份的高低。兩者可能方向相反。
- **托育使用率**：0–2 歲幼兒中，在托嬰中心或登記居家托育人員處被收托的比例。托育多的地方生育率較高，也可能是因為孩子多的地方設了更多托育；兩者的關聯不代表托育提高了生育。
- **推估情境**：國發會的高、中、低推估是三組不同的生育率假設，不是三種可能性的機率。中推估不等於「最可能」，三者之間也不是誤差範圍。
- **推估出生數分解**：把推估出生數的變化拆成育齡女性人數、年齡結構與推估生育率三部分。前兩項由已經出生的世代決定，即使生育率回升也很難改變。
- **關聯與原因**：散布圖、相關係數與模型係數描述的是地區之間的共同變動，可能來自其他共同因素或反向關係，不是一個因素造成另一個的證據。

## 限制

- 所有數字都是戶籍登記統計（年度數字按發生日期），地區依戶籍歸屬，不一定是實際居住地；未設籍的外籍人士不在其中。
- 年中育齡女性以相鄰兩年年底人數平均估算。官方總生育率是把四捨五入後的整數年齡別生育率相加，本站使用未四捨五入的自算值，與官方值的差距列在資料說明頁。
- 2010 年底以前的臺北縣、桃園縣，以及臺中、臺南、高雄的縣與市，都已對應到現行縣市：人數相加、比率重算；合併前沒有共同口徑的平均年齡留空。
- 鄉鎮市區人數少，單年比率波動大；預設呈現三年合併的值，並標示年出生數少於 20 人或育齡女性少於 1,000 人的地區。
- 2019 年的胎次檔把高雄市三民區、鳳山區記為 0 人（與鄉鎮市區出生數不符），本站將這兩區當年視為缺漏，不補值。
- 出生數分解是人口會計恆等式：三個部分加總恰等於實際變化，但不能把「年齡別生育率」一項解讀為意願、政策成敗或任何原因。
- 有偶比例與有偶婦女生育率的分解只做全國：縣市沒有各年齡有偶人口的歷年公開表。有偶婦女生育率的分子包含非婚生嬰兒，與官方口徑相同。
- 因素頁呈現地區層級的描述性關聯：可能來自共同原因、反向關係或人口組成差異，不代表因果，也不能推論到個別家庭（生態謬誤）。縣市只有 22 個，叢集穩健區間較寬，請同時看逐一剔除縣市的範圍。
- 縣市所得為主計總處家庭收支調查的平均每戶可支配所得（抽樣調查，小縣市誤差較大；金門縣、連江縣不在調查範圍）。鄉鎮市區所得為綜合所得稅申報的「每納稅單位」所得中位數，只有 2012–2023 年，2018 年起股利可分開計稅，各年口徑不完全一致。教育程度為 15 歲以上兩性合計。
- 托育使用率的分子是在托嬰中心或登記居家托育人員處收托的幼兒，不含親屬照顧與未登記的保母；分母是戶籍 0–2 歲人口，跨縣市就托會讓個別縣市偏高或偏低。居家托育 2016 年改為登記制，人數與收托數在 2015、2016 年之間不能比較。幼兒園就讀率以學年度幼生數除以同年年底 2–5 歲人口，幼生可能含 6 歲，屬近似值。
- 人口推估是國發會在特定生育、死亡與遷移假設下的情境，不是預測。本站以推估表本身的年齡別生育率與女性人數重建出生數，與國發會公布值的差距列在資料說明頁；推估期間各年的分解與托育名額都只是機械式情境。
- 本版未納入房價負擔與女性勞動參與，也沒有縣市層級的人口推估，留待後續版本。
